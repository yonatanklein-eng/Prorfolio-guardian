# שומר התיק

דף סטטי שעוקב אחרי מצב השוק: S&P 500 מול קו 200, מחירים חיים, מדד סיכון ורוחב שוק.

## למה יש כאן Worker

הדף מתארח ב־GitHub Pages בלי שרת, ולכן כל בקשה שהוא שולח כפופה ל־CORS.
אף אחד מספקי הדאטה החינמיים לא מאפשר קריאה אמינה מדפדפן, ובנוסף:

- **Finnhub** — ה־free tier מכסה מניות ותעודות סל אמריקאיות בלבד.
  `/stock/candle`, כלומר כל ההיסטוריה, הוא premium
  ([finnhubio/Finnhub-API#546](https://github.com/finnhubio/Finnhub-API/issues/546)).
- **Yahoo** — אין CORS, וה־API הרשמי הוצא משימוש.
- פרוקסי CORS ציבוריים חינמיים — מוגבלי קצב, לא יציבים, וחלקם כבר מתים.

בצד השרת אין CORS בכלל. `worker.js` קורא מה־upstream שבריא כרגע ומחזיר
לדף תשובה שמותר לו לקרוא. הוא גם שומר תוצאות במטמון — היסטוריה של
מאתיים יום משתנה פעם ביום, אז בקשה אחת משרתת את כל הטעינות.

## חלוקת המקורות

| מה | מאיפה | הערה |
|---|---|---|
| מחירים חיים | Finnhub ישירות, דרך תעודות סל | מכוסה ב־free tier, לא צריך Worker |
| היסטוריה לקו 200 ולגרף | Worker, מ־Yahoo ובנפילה Stooq | Finnhub חוסם |
| רוחב שוק | Worker | `^S5TH` בבקשה אחת, ובנפילה מדגם |

## פריסת ה־Worker

1. `dash.cloudflare.com` ← Workers & Pages ← Create ← Start from Hello World
2. להדביק את התוכן של `worker.js` ולפרוס
3. לערוך את `ALLOWED` בראש הקובץ כך שיכיל את ה־origin שלך
4. להעתיק את כתובת ה־`*.workers.dev` ולהדביק אותה באפליקציה, עמוד המחירים

המסלול החינמי נותן מאה אלף בקשות ביום. בזכות המטמון השימוש בפועל הוא
עשרות בודדות.

**מגבלה שכדאי להכיר:** במסלול החינמי יש תקרה של חמישים בקשות־משנה לכל
קריאה, ולכן סריקה מלאה של חמש מאות מניות לא אפשרית ב־Worker. לכן
`/breadth` מנסה קודם את `^S5TH` — בקשה אחת — ורק אם הוא לא זמין נופל
למדגם, ואז **מסמן את עצמו** כמדגם בשדה `method`, כדי שהדף לא יציג מספר
שנראה סמכותי יותר ממה שהוא.

## בדיקות

```
node worker.test.mjs
```

עשרים ושמונה בדיקות עם upstream מדומה: יישור תאריכים מול סגירות, נפילה
בין מקורות, החזרת 502 בלי מטמון כששני המקורות נופלים, בחירת מקור רוחב
השוק, ו־CORS. שתיים מהן נכתבו אחרי שתפסו באגים אמיתיים — פרסום ערך
מחוץ לטווח כאחוז, ורף מינימלי שחסם את `/quote`.

## אבחון

`diag.html` בודק מאיזה מקורות הדפדפן באמת מצליח למשוך נתונים.
חייב לרוץ מה־origin האמיתי — CORS נקבע לפי origin, ופתיחת הקובץ
מהמחשב נותנת `null` ותוצאה חסרת ערך.
