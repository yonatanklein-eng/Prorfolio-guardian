# שומר התיק

דף סטטי שעוקב אחרי מצב השוק: S&P 500 מול קו 200, מחירים, מדד סיכון ורוחב שוק.

## מאיפה מגיעים הנתונים

הדף מתארח ב־GitHub Pages בלי שרת, ולכן כל בקשה שהוא שולח כפופה ל־CORS.
אף אחד מספקי הדאטה החינמיים לא פותר את זה במלואו:

- **Finnhub** — ה־free tier מכסה מניות ותעודות סל אמריקאיות בלבד. אין
  אינדקסים, אין מט"ח, ו־`/stock/candle` — כלומר כל ההיסטוריה — הוא premium
  ([finnhubio/Finnhub-API#546](https://github.com/finnhubio/Finnhub-API/issues/546)).
- **Yahoo** — אין CORS, וה־API הרשמי הוצא משימוש.
- **Alpha Vantage** — אין CORS, ועשרים וחמש בקשות ליום.
- **Stooq** — דורש מפתח API מאז תחילת 2026 ומחזיר דף HTML בלעדיו
  ([pandas-datareader#1012](https://github.com/pydata/pandas-datareader/issues/1012)).
- פרוקסי CORS ציבוריים חינמיים — מוגבלי קצב, לא יציבים, וחלקם מתים.

הפתרון הוא לא למשוך הכול מהדפדפן:

אף ספק חינמי אחד לא מכסה את כל מה שהעמוד צריך, ולכן הנתונים מגיעים משילוב:

| מה | מאיפה | חי? |
|---|---|---|
| מניות ותעודות סל אמריקאיות | Finnhub, מהדפדפן | ✅ |
| דולר/שקל, יורו/דולר | Frankfurter (שערי ECB), מהדפדפן | שער רשמי יומי |
| ביטקוין | CoinGecko, מהדפדפן | ✅ |
| היסטוריה, קו 200, רוחב שוק, מאקרו | `data/market.json` | נאסף פעם ביום |
| ת"א 125 | `data/market.json` | אין מקור חינמי חי |

**Frankfurter** ו־**CoinGecko** חינמיים לגמרי, בלי מפתח, ומתועדים כמיועדים
לקריאה ישירה מהדפדפן — ולכן הם עובדים מדף סטטי בלי שום תשתית.

### למה תעודות סל

`^GSPC` לא זמין ב־free tier, אבל `SPY` כן. אחוז השינוי היומי של תעודת הסל
עוקב מקרוב אחרי הנכס, וזה מה שהעמוד מציג. **הרמה המוחלטת שונה** — GLD הוא
בערך עשירית אונקיית זהב — ולכן כל שורה נושאת את שם התעודה בכותרת, כדי שלא
יופיע מספר לא נכון תחת תווית נכונה.

לרמה המוחלטת של המדד יש טריק: לוקחים את סגירת אתמול האמיתית ומחילים עליה
את אחוז השינוי החי של SPY.

## האיסוף היומי

`.github/workflows/market-data.yml` רץ שלוש פעמים ביום בימי חול ומריץ את
`scripts/fetch-market.mjs`. הוא כותב את
`data/market.json`, מקמט אותו לריפו ומפרסם מחדש את האתר.

בצד השרת אין CORS ואין מפתח שנחשף, ואפשר לשמור מצב בין הרצות — מה שבדפדפן
לא היה אפשרי.

### רוחב שוק — שלוש שכבות

ה־endpoint של Yahoo הוא **לא API רשמי**: לא מתועד, הוצא משימוש, וחוסם לפי
קצב. הטעות הראשונה כאן הייתה להניח שצריך בקשה נפרדת לכל מניה. לא צריך.

1. **`^S5TH` — בקשה אחת.** אינדקס שמפרסם בדיוק את הסטטיסטיקה הזאת.
2. **`v7/finance/quote` בבאצ'ים — עשר בקשות.** ה־endpoint מקבל חמישים
   סימבולים בקריאה ומחזיר שדה `twoHundredDayAverage` מוכן לכל אחד, כך
   שאין מה לחשב מהיסטוריה. כל 500 המניות, אותו יום, בשלוש שניות.
   הוא דורש crumb ועוגייה — מביאים עוגייה מ־Yahoo, פודים אותה ב־crumb,
   ושומרים לעשרים וחמש דקות. crumb שנדחה מנקה את המטמון ומנסה שוב פעם אחת.
3. **רוטציה — רק אם שתי הראשונות נופלות.** שישים מניות בהרצה, המצב נשמר
   ב־`breadthState`, והכיסוי נבנה על פני כמה ימים. מתחת למאה מניות ידועות
   הוא מסמן `building` ולא מפרסם מספר בכלל.

התוצאה מסמנת את עצמה ב־`method` — `index`, `batch:N`, `rotating:N` או
`building` — והדף מציג את זה. ברוטציה הוא מציג גם כמה זמן עבר מאז הבדיקה
הוותיקה ביותר, כי קריאה ברוטציה היא פסיפס של ימים שונים ולא צילום רגע.

להרצה ידנית: לשונית Actions ← Collect market data ← Run workflow.

## הרצה מקומית

```
node scripts/fetch-market.mjs    # כותב data/market.json
python3 -m http.server 8080      # חייב שרת; fetch לא עובד מ-file://
```

## בדיקות

```
node worker.test.mjs
```

שלושים וחמש בדיקות עם upstream מדומה: יישור תאריכים מול סגירות, נפילה בין
מקורות, החזרת 502 בלי מטמון כשכולם נופלים, בחירת מקור רוחב השוק, ו־CORS.
כמה מהן נכתבו אחרי שתפסו באגים אמיתיים — פרסום ערך מחוץ לטווח כאחוז
("499% מהמניות מעל קו 200"), רף מינימלי שחסם את `/quote`, ודף ה־HTML
ש־Stooq מחזיר בלי מפתח ושאסור שייקרא כסדרת נתונים.

### שרשרת המקורות בצד השרת

`FRED ← Yahoo ← Stooq`, והסדר נקבע לפי מדידה ולא לפי העדפה.
`scripts/probe.mjs` רץ על runner של GitHub והחזיר:

| מקור | תוצאה מה־runner |
|---|---|
| Yahoo — query1, query2, getcrumb | **429 על הבקשה הראשונה, תמיד** |
| Stooq | 200, אבל דף בקשת מפתח ולא CSV |
| FRED | נגיש, דורש מפתח |
| Frankfurter, CoinGecko, Alpha Vantage, Nasdaq | ✅ |

כלומר Yahoo לא זמין משרתי GitHub בכלל — טווחי ה־IP המשותפים חסומים אצלו.
לכן FRED מוביל בצד השרת. בדפדפן, או בכל מקום שבו Yahoo כן נגיש, FRED מדלג
על עצמו בהיעדר מפתח ו־Yahoo עונה — אותה שרשרת עובדת בשני המקומות בלי לדעת
איפה היא רצה.

**המפתח של FRED הוא מה שמפעיל את האיסוף.** הוא חינמי ומיידי:
הרשמה ב־fred.stlouisfed.org/docs/api/api_key.html, ואז בריפו
Settings ← Secrets and variables ← Actions ← New repository secret,
בשם `FRED_API_KEY`.

בלי המפתח האיסוף רץ ונכשל בקול — הוא לא מקמט קובץ ריק.

## `worker.js` — אופציונלי

פרוקסי ל־Cloudflare Workers, למי שרוצה נתונים טריים יותר מפעם ביום.
**לא נדרש** — האפליקציה עובדת בלעדיו לגמרי. הוא גם מחזיק את הלוגיקה של
משיכת הנתונים, ש־`scripts/fetch-market.mjs` מייבא ממנו, כדי שלא יהיו שתי
עותקים שנסחפים אחד מהשני.

לפריסה: `dash.cloudflare.com` ← Workers & Pages ← Create ← להדביק ← לערוך
את `ALLOWED` ל־origin שלך.

## `diag.html`

בודק מאיזה מקורות הדפדפן באמת מצליח למשוך נתונים. חייב לרוץ מה־origin
האמיתי — CORS נקבע לפי origin, ופתיחת הקובץ מהמחשב נותנת `null` ותוצאה
חסרת ערך.
