# שומר התיק

דף סטטי שעוקב אחרי מצב השוק: S&P 500 מול קו 200, מחירים, מדד סיכון ורוחב שוק.

## מאיפה מגיעים הנתונים

הדף מתארח ב־GitHub Pages בלי שרת, ולכן כל בקשה שהוא שולח כפופה ל־CORS.
אף אחד מספקי הדאטה החינמיים לא פותר את זה במלואו:

- **Finnhub** — ה־free tier מכסה מניות ותעודות סל אמריקאיות בלבד. אין
  אינדקסים, אין מט"ח, ו־`/stock/candle` — כלומר כל ההיסטוריה — הוא premium
  ([finnhubio/Finnhub-API#546](https://github.com/finnhubio/Finnhub-API/issues/546)).
- **Yahoo** — אין CORS, וה־API הרשמי הוצא משימוש.
- פרוקסי CORS ציבוריים חינמיים — מוגבלי קצב, לא יציבים, וחלקם מתים.

הפתרון הוא לא למשוך הכול מהדפדפן:

| מה | מאיפה | הערה |
|---|---|---|
| מחירים חיים | Finnhub ישירות, דרך תעודות סל | מכוסה ב־free tier |
| היסטוריה, קו 200, גרף | `data/market.json` | נאסף פעם ביום בצד השרת |
| רוחב שוק | `data/market.json` | נספר פעם ביום |
| מט"ח, ת"א 125 | `data/market.json` | אין להם תעודת סל אמריקאית |

### למה תעודות סל

`^GSPC` לא זמין ב־free tier, אבל `SPY` כן. אחוז השינוי היומי של תעודת הסל
עוקב מקרוב אחרי הנכס, וזה מה שהעמוד מציג. **הרמה המוחלטת שונה** — GLD הוא
בערך עשירית אונקיית זהב — ולכן כל שורה נושאת את שם התעודה בכותרת, כדי שלא
יופיע מספר לא נכון תחת תווית נכונה.

לרמה המוחלטת של המדד יש טריק: לוקחים את סגירת אתמול האמיתית ומחילים עליה
את אחוז השינוי החי של SPY.

## האיסוף היומי

`.github/workflows/market-data.yml` רץ בימי חול ב־22:00 UTC, אחרי סגירת
המסחר בארה"ב, ומריץ את `scripts/fetch-market.mjs`. הוא כותב את
`data/market.json`, מקמט אותו לריפו ומפרסם מחדש את האתר.

בצד השרת אין CORS, אין תקרת בקשות־משנה, ואין מפתח שנחשף. לכן דווקא שם
**ספירת רוחב השוק היא ספירה אמיתית של כל 500 המניות** — מה שבדפדפן היה
חמש מאות בקשות בכל טעינת עמוד דרך פרוקסי מוגבלי קצב, ולכן בדרך כלל נכשל.

הסקריפט מנסה קודם את `^S5TH`, שהוא בדיוק אותה סטטיסטיקה שכבר מחושבת
ומפורסמת כאינדקס, ורק אם הוא לא זמין הוא סופר בעצמו. התוצאה **מסמנת את
עצמה** בשדה `method` — `index`, `census` או `sample` — והדף מציג את זה,
כדי שמדגם לא ייראה כמו ספירה מלאה.

להרצה ידנית: לשונית Actions ← Collect market data ← Run workflow.

## הרצה מקומית

```
node scripts/fetch-market.mjs    # כותב data/market.json
python3 -m http.server 8080      # חייב שרת; fetch לא עובד מ-file://
```

## בדיקות

```
node worker.test.mjs
```

עשרים ושמונה בדיקות עם upstream מדומה: יישור תאריכים מול סגירות, נפילה בין
מקורות, החזרת 502 בלי מטמון כששני המקורות נופלים, בחירת מקור רוחב השוק,
ו־CORS. שתיים מהן נכתבו אחרי שתפסו באגים אמיתיים — פרסום ערך מחוץ לטווח
כאחוז ("499% מהמניות מעל קו 200"), ורף מינימלי שחסם את `/quote`.

## `worker.js` — אופציונלי

פרוקסי ל־Cloudflare Workers, למי שרוצה נתונים טריים יותר מפעם ביום.
**לא נדרש** — האפליקציה עובדת בלעדיו לגמרי. הוא גם מחזיק את הלוגיקה של
משיכת הנתונים, ש־`scripts/fetch-market.mjs` מייבא ממנו, כדי שלא יהיו שתי
עותקים שנסחפים אחד מהשני.

לפריסה: `dash.cloudflare.com` ← Workers & Pages ← Create ← להדביק ← לערוך
את `ALLOWED` ל־origin שלך.

## `diag.html`

בודק מאיזה מקורות הדפדפן באמת מצליח למשוך נתונים. חייב לרוץ מה־origin
האמיתי — CORS נקבע לפי origin, ופתיחת הקובץ מהמחשב נותנת `null` ותוצאה
חסרת ערך.
